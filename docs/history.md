# Java 发展历史

## 0x01 Java 起源与诞生
- Oak 项目（1991）由 James Gosling、Mike Sheridan、Patrick Naughton 等在 Sun Microsystems 启动，最初目标是为家庭/嵌入式设备提供跨平台的编程解决方案。  
- 1995 年，Oak 改名为 Java，正式确立跨平台网络应用的定位。  
- Java 1.0 发布（1996），标志着 Java 的正式商业化起步和广泛应用的开端。  
- Write Once, Run Anywhere（一次编写，到处运行，WORA）理念成为 Java 设计与跨平台实现的核心驱动力，推动虚拟机和跨平台 API 的发展。

## 0x03 Java 版本演进历史
- JDK 1.0（1996）—— Java 的首个稳定版本，奠定跨平台虚拟机和核心类库基础。  
- JDK 1.1（1997）—— API 重大扩展与改进，增强了事件模型、RMI、JDBC 等能力。  
- J2SE 1.2（1998）—— 引入 Swing、集合框架等，显著提升开发效率与 UI 能力。  
- J2SE 1.3（2000）—— 性能与可靠性持续提升，适配更多平台与场景。  
- J2SE 1.4（2002）—— 引入断言（assertion）、正则表达式等语言/库层面的实用特性。  
- J2SE 5.0（2004）—— 泛型、枚举类型、注解、自动装箱等语言层面的重大改进，带来更强的类型安全和元编程能力。  
- Java SE 6（2006）—— 重点在总体性能、桌面和 Web 应用的改进，以及对更广泛平台的支持。  
- Java SE 7（2011）—— 引入 Diamond 语法、try-with-resources 等语言特性，简化代码和资源管理。  
- Java SE 8（2014）—— Lambda 表达式、Stream API、Optional 等函数式编程特性和流式处理。  
- Java SE 9（2017）—— 模块系统（Project Jigsaw），带来应用模块化和依赖管理的新维度。  
- Java SE 10（2018）—— 局部变量类型推断（var）带来更简洁的声明方式。  
- Java SE 11（2018）—— LTS（长期支持）版本，成为企业选型的稳定基线。  
- Java SE 12-16（2019-2021）—— 各种语言与工具链改进（如模式匹配的迭代、文本块、switch 表达式等持续演进，增强开发体验与性能提升）。  
- Java SE 17（2021）—— LTS 版本，包含 Sealed Classes 等新的类型系统特性，继续推动长期可维护性与语义清晰度。  

## 0x04 Oracle 收购 Sun (2010)
- 收购过程：2009 年，Oracle 公布对 Sun Microsystems 的收购计划，交易在 2010 年完成，交易金额约 74 亿美元。收购使 Java 的未来治理与发展进入 Oracle 主导阶段，同时推动对 OpenJDK 的开放社区化治理与持续演进。  
- 对 Java 发展的影响：引入了更明确的商业与开源协作框架，推动 OpenJDK 作为主要的开放实现与社区共同体的发展；同时也带来对许可证、商业发行及法律纠纷等方面的关注与讨论，促使 Java 生态在开放与商业之间寻找平衡。  

> 注：本部分内容聚焦时间线与核心影响，帮助读者理解从 Sun 的创新到 Oracle 的整合对 Java 生态的驱动与变迁。

## 0x05 OpenJDK 与开源
- 2006 年开源：Sun 将 Java 的参考实现逐步开源，OpenJDK 成为推动 Java 生态开放的核心项目。  
- OpenJDK 社区：由全球开发者、企业和组织共同维护，采用开源治理模型，鼓励跨厂商贡献。  
- 贡献模式：通过邮件列表、代码审查、补丁提交等方式进行协作，OpenJDK 的开发与发布周期逐步与商业发行并行推进，形成稳定的长期支持与快速迭代并存的生态。
